# BPMN Diagram — Процесс возврата товара

## Задача
Спроектировать процесс обработки возвратов товаров с участием покупателя, 
системы маркетплейса и сотрудника поддержки.

## Контекст
Из-за роста аудитории увеличилось количество возвратов. 
SLA на обработку заявки — не более 2 часов.

## Участники процесса
- **Покупатель** — инициирует возврат
- **Система маркетплейса** — автоматически проверяет условия возврата
- **Сотрудник поддержки** — принимает финальное решение

## Основные шаги
1. Покупатель создаёт заявку с причиной и фото товара
2. Система проверяет срок (14 дней), состояние товара и соответствие политике
3. При успешной проверке — заявка уходит сотруднику поддержки
4. Сотрудник проверяет детали, при необходимости связывается с покупателем
5. Решение: одобрить (назначить способ возврата) или отклонить с комментарием
