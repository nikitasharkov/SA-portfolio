# Use Case Diagram — Управление брендами

## Задача
Задокументировать варианты использования для функционального блока управления брендами маркетплейса.

## Контекст
Маркетплейс запускает отдельную страницу для товаров категории «одежда». 
Два типа пользователей работают с брендами по-разному.

## Актёры
- **Пользователь** — просматривает и ищет бренды, переходит к товарам
- **Контент-менеджер** — создаёт, изменяет и удаляет бренды

## Use Cases
| Актёр | Сценарий |
|-------|----------|
| Пользователь | Просмотр списка брендов |
| Пользователь | Поиск бренда по названию |
| Пользователь | Сортировка брендов по алфавиту |
| Пользователь | Переход к товарам бренда |
| Контент-менеджер | Создание бренда (название, логотип, коллекция) |
| Контент-менеджер | Изменение бренда |
| Контент-менеджер | Удаление бренда |
