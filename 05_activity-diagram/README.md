# Activity Diagram - Резервирование товаров на складах

## Задача
Спроектировать процесс параллельного и асинхронного резервирования 
товаров на складах при оформлении заказа.

## Контекст
Маркетплейс работает с десятками складов и FBS-продавцами. 
При заказе нескольких товаров резервирование происходит параллельно 
через брокер сообщений Kafka.

## Участники / сервисы
| Участник | Роль |
|----------|------|
| Пользователь | Создаёт заказ |
| Сервис заказов | Принимает и обрабатывает заказ |
| БД заказов | Хранит статусы заказов |
| Сервис проверки остатков | Проверяет наличие и рекомендует склад |
| Kafka | Асинхронная отправка команд резервирования |

## Ключевые моменты
- Статус заказа: `CREATED` → `RESERVED`
- Товары группируются по складам
- Команды резервирования отправляются параллельно для каждого склада
