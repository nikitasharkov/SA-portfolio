# Документирование требований - Маркетплейс

## Задача
Сформулировать верхнеуровневые бизнес-требования к системе маркетплейса на основе запросов стейкхолдеров.

## Что сделано
Описаны бизнес-требования по 8 функциональным блокам:

| Блок | Описание |
|------|----------|
| Управление каталогом и брендами | Иерархический каталог, CRUD брендов |
| Управление товарами | Создание, редактирование, дедупликация |
| Оформление заказов | Корзина, резервирование, статусы |
| Платежи и возвраты | Процесс возврата, SLA 2 часа |
| Доставка и трекинг | ПВЗ, курьер, отслеживание статусов |
| Уведомления | Email/push через webhook |
| ИИ-помощник | Диалоговый чат, рекомендации |
| Аутентификация и роли | Пользователи, контент-менеджеры, администраторы |
