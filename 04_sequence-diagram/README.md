# Sequence Diagram - Работа с брендами на маркетплейсе

## Задача
Спроектировать взаимодействие пользователя с системой при работе 
со страницей брендов маркетплейса.

## Контекст
Страница брендов в категории «одежда» позволяет пользователям 
искать, фильтровать и просматривать бренды.

## Покрытые сценарии
- Поиск бренда по названию
- Просмотр списка брендов
- Сортировка брендов по алфавиту
- Переход к товарам и баннерам выбранного бренда

## Инструменты
PlantUML
